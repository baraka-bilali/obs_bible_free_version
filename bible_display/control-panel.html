Settings

Customize the display and this control panel.

General

Language Interface language for the control panel.

Typography

Reference Font Size Scales the font size of the verse reference display.
Verse Font Size Scales the font size of displayed Bible verses.
Reference font Font used for the verse reference (e.g. Genesis 1:1).
Verse font Font used for the Bible verse text.
Line Spacing Controls the line height of the verse text.
Maximum number of lines Minimum banner height in lines. Without splitting, the chosen font size is kept and the banner grows if needed. 0 = no limit.

Display

Split long verses On: long verses are split into navigable slides. Off: the whole verse stays on one slide.
Opacity Controls the transparency of the verse display block.
Opacity target Choose what the opacity affects: entire block, background, or text.
Text Alignment Sets the text alignment for the verse display.

Text style

Verse weight Boldness of the verse text.
Verse style Italic and underline for the verse text.
Verse letter spacing Space between letters of the verse text.
Reference weight Boldness of the verse reference.
Reference style Italic style for the verse reference.
Reference letter spacing Space between letters of the reference.
Capitalisation Transform verse text to uppercase or lowercase.

Behavior

Transition Effect Animation used when displaying and hiding verses.
Auto-hide Verse Hides the verse after the delay (like the eye button). It stays hidden until you show it again.
Auto-hide Delay Number of seconds before the verse disappears.
